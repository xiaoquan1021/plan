# XQ Ledger

This directory contains public task definitions, schemas, fixture registry, migration declarations, and generated public snapshots.

## Authoritative Inputs

- `task-definitions/`: public planning task definitions.
- `schema/`: schemas for definitions, contracts, templates, fixtures, migration, and projections.
- `fixtures/fixture-manifest.json`: fixture registry only, not sensitive data.
- `migrations/`: deterministic migration declarations.

## Private Runtime Inputs

Private runtime truth is excluded from public Git and may be provided only through logical bindings:

- `PRIVATE_RUNTIME_LEDGER`
- `PRIVATE_COMPLETION_RECORDS`
- `WORKSPACE_RECONCILIATION_REPORT`

## Generated Outputs

`snapshots/` is generated by `harness/generate_snapshots.py`. Do not edit snapshot files by hand.

## Completion Claims

Do not treat old Markdown checkmarks, historical summaries, or documentation completion as implementation completion. Implementation completion requires valid runtime projection plus Codex B Gate Results. Acceptance requires Codex A Epic Review.
