# Final Acceptance Contract

## Acceptance Levels

- L0 synthetic contract tests prove core semantics and small integration paths.
- L1 de-identified fixture tests prove the minimum project slice with safe public or restricted data.
- L2 real full acceptance proves the complete product against a real project under privacy controls.

## L2 Required Capabilities

L2 must cover image, path, contour, segmentation, surface model, mesh, simulation case, save/reopen, diagnostics, and performance.

## Performance Categories

Each performance metric must define measurement method, dataset/fixture, machine profile, number of runs, aggregation, threshold, and evidence artifact.

Required categories:

- application startup time
- project open time
- peak memory
- viewer responsiveness / frame rate
- save time
- reopen time
- large-project failure behavior
- diagnostics generation time

Thresholds are `OPEN-DECISION` and must be approved before XQ-M9.
